# Gen2 Upstream / Downstream and Root Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Gen2 `MODE=RC` train as a Downstream port, expose a Type 1 bridge header, and send one Type 1 config write plus one Type 1 config read, with USP and DSP as aliases of the two ports.

**Architecture:** Keep the Gen2 8b/10b MAC, DLL, and 64-bit CQ/CC/RQ/RC ports. Split behavior on the existing `IS_DOWNSTREAM` predicate (`RC` or `DSP`). Slice 1 fixes LTSSM polarity and the UVM peer role. Slice 2 swaps the config-space reset image. Slice 3 teaches `rivet_tl_rq` to emit CfgRd1/CfgWr1 from the PG213 requester descriptor. Slice 4 only proves USP and DSP. Gen3 stays in `docs/superpowers/plans/2026-11-23-gen3-ep.md` and does not start.

**Tech Stack:** SystemVerilog, `rivet_pkg`, Questa UVM (`scripts/sim_questa.ps1`), Verilator lint (`scripts/lint.ps1`).

**Design:** `docs/gen2-port-roles.md`

## Global Constraints

- English only in code, comments, commits, and docs.
- Active generation is Gen2. `GEN` elaborates as 1 or 2 only. `PIPE_DATA_WIDTH` stays 16. No 128b/130b and no Recovery.Equalization.
- `LANES` stays in {1, 2, 4}. New gates are ×4. Do not drop ×1 or ×2.
- No vendor cells in `rtl/pcie_ctrl/`.
- User boundary stays AXI-ST CQ/CC/RQ/RC plus `cfg_mgmt`. No AXI-Lite.
- Default UVM DUT remains `MODE=0` (EP) unless the test's compile define says otherwise.
- A Gen2 EP smoke that passes today must still pass after each slice. Minimum set after every slice: `ltssm_l0_gen2_x4`, `smoke_hot_reset_gen2_x4`, `smoke_disabled_gen2_x4`, `smoke_cfg_mgmt_gen2_x4`, `smoke_tlp_rq_memwr_gen2_x4`.
- Do not paste proprietary spec text into the tree.
- Commits: `feat|fix|test|docs|build(scope): ...` with no Cursor attribution.
- Quote a test as PASS only after the command printed that result.
