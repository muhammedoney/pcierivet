# Gen3 then Gen4 Endpoint Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring `rivet_pcie_ctrl` to Gen3 x4 Endpoint L0 with one posted write and one completion, then to Gen4 x4 the same way, while every current Gen2 smoke still passes.

**Architecture:** Training still starts at 2.5 GT/s on the 16-bit pipe. Gen3 is PIPE rate `2` (8 GT/s), 32 bits per lane, 128b/130b blocks, and four Recovery.Equalization phases. Gen4 is PIPE rate `3` (16 GT/s) and 64 bits per lane on the same block encoding. The Endpoint is the upstream slave. The UVM Downstream peer is the equalization master. Gen2 remains the default elaboration. Gen4 tasks do not start until the Gen3 TLP gate is green.

**Tech Stack:** SystemVerilog, `rivet_pkg`, Questa UVM, Verilator lint. PG213 Root Port serial bench is optional confidence after UVM L0, not the protocol gate.

## Global Constraints

- English only in code, comments, commits, and docs.
- `MODE=EP` for every new test. Lanes stay in {1, 2, 4}. No vendor cells in `rtl/pcie_ctrl/`.
- Default elaboration stays `GEN=2` and `PIPE_DATA_WIDTH=16`. A Gen3 test passes `GEN=3` and `PIPE_DATA_WIDTH=32`. A Gen4 test passes `GEN=4` and `PIPE_DATA_WIDTH=64`.
- Do not widen the user AXI-ST ports. They stay 64-bit.
- Do not implement Gen5, message-bus margining, or a second Rivet controller as the link partner.
- Do not paste proprietary spec text into the tree. `specs/` stays untracked.
- A Gen2 smoke that passes today must still pass after each slice.
- Quote timing and megabytes per second only from a run that printed them.
- Do not start a Gen4 task until Task 6 has passed.
- USP, DSP, and RC stay on the Gen2 image. Equalization code still keys off `IS_DOWNSTREAM`, but only the upstream slave is tested here.
- Commit style: `feat|fix|test|docs|build|chore|refactor(scope): ...`. No Cursor attribution. Do not push.

## Link partner

The Endpoint under test is upstream. The equalization master is the Downstream port, which in the UVM bench is `tb/uvm/agents/rivet_pipe_ltssm_peer.svh`. Extend that peer. Do not add a second Rivet DUT and do not validate Gen3 by looping Rivet against itself.

A PG213 Root Port serial run is allowed only after `smoke_gen3_l0_x4` is green, and only if that example IP is generated with an 8 GT/s cap. The current RC bench advertises Gen1 (`SPEED_CHANGE_EN=0`). Do not retune it inside this plan. A missing or Gen1-only vendor model does not fail the UVM gate.
